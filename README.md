## About

I build software at the intersection of backend engineering, applied AI, automation and infrastructure.

My main interest is turning AI from a conversational interface into a reliable component of a software system: agents that can use tools, access structured knowledge, execute workflows and verify their results.

I approach AI as an engineering discipline, combining conventional software architecture with experimentation, automated testing, observability and reproducible evaluation.

## Engineering focus

| Area | What I work on |
| :--- | :--- |
| **Applied AI & LLM applications** | Integrating language models with APIs, tools, structured data and application workflows. |
| **Agentic systems** | Planning and execution workflows, model selection, tool integration, review and verification loops. |
| **Developer productivity** | AI-assisted code review, automated documentation, knowledge retrieval and repetitive engineering tasks. |
| **Backend engineering** | API design, service architecture, relational databases, data processing and integration testing. |
| **Infrastructure & automation** | Containerized services, CI/CD, self-hosting, monitoring and deployment workflows. |
| **Frontend engineering** | Web interfaces, interactive visualizations and practical interfaces for complex applications. |

## Experience

### Software engineering

- Backend development with C#, .NET, relational databases and HTTP APIs.
- Development and maintenance of existing applications, integrations and automated tests.
- Build and delivery workflows with Docker, Jenkins and Git.
- Monitoring and diagnostics with Prometheus and Grafana.

### Applied AI & engineering automation

- AI-assisted code review using repository context, documentation and issue-tracking integrations.
- Automated documentation workflows that turn software changes into structured, searchable knowledge.
- Model Context Protocol (MCP) integrations connecting AI agents to external tools and services.
- Experimentation with model routing, local inference, task decomposition and cost-aware execution.
- Designing verification steps and human approval boundaries for consequential operations.

## Engineering principles

- Make workflows reproducible, observable and testable.
- Prefer measurable outcomes over impressive-looking demos.
- Keep architecture understandable and documentation close to the code.
- Treat AI-generated output as something to validate, not automatically trust.
- Automate repetitive work while preserving control over important decisions.
